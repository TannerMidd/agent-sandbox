# Security policy

## Supported versions

Only the most recent public beta receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a suspected vulnerability. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real credentials or personal data.

Maintainers will acknowledge a valid report, coordinate a fix and disclosure window, and credit reporters who want attribution. No bounty is currently offered.

## Scope priorities

High-priority areas include elevated-helper request validation, installer/preset integrity, Multipass target confusion, host path containment, symlink/reparse traversal, archive extraction, transfer atomicity, confirmation bypass, secret leakage, and diagnostic redaction.
